# asp_deriv
This is a repository with a sample code used in "Automatic detection of grammatical aspect of Russian verbs based on their morphological properties"

If you use asp-deriv, please cite the following paper:

Petrunina, Uliana, and Hana Filip. "Automatic detection of grammatical aspect of Russian verbs based on their morphological properties." Fourth International Workshop on Resources and Tools for Derivational Morphology. Vol. 5. 2023. [URLPaperDeriMo2023](https://derimo.ffzg.unizg.hr/media/uploads/proceedings/derimo2023.pdf#page=22)
